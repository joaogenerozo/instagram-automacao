# Estudos de caso reais (prova social)

A conta ainda não tem nenhum cliente real mostrado, e isso é o que mais pesa na decisão de contratar.
Meta: 2 ou 3 projetos reais com negócios de Andradas e região (pode ser com desconto em troca de autorização para mostrar e de um depoimento).

## Antes de publicar
1. Autorização por escrito (WhatsApp serve) para mostrar o nome, o site e o depoimento.
2. Prints reais do projeto (celular e computador) em `midia/casos/<slug>/`.
3. Depoimento com as palavras do cliente, sem editar o sentido. Nada de números que o cliente não confirmou.
4. @ do Instagram do cliente para o collab.

## Estrutura do carrossel de caso (7 lâminas)
1. Capa: "Como ficou o site da <negócio>, em <cidade>" + print no celular.
2. O problema antes (nas palavras do cliente).
3. O que foi feito (3 a 4 funcionalidades reais).
4. Print do celular.
5. Print do computador.
6. Depoimento real (aspas + nome + negócio).
7. CTA: "Quer um assim? Comente SITE".

## Na fila
Adicione ao item: `"colaboradores": ["@contadocliente"]`. O post aparece no perfil do cliente também, para os seguidores dele, depois que ele aceitar o convite.
Remova o aviso "Demonstração ilustrativa" só nesses posts reais.
